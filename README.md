# Brush&Bliss

A responsive React + Vite frontend for an art website featuring resin art, mandala art, Tanjore art, fabric painting, canvas painting, texture art, home decor, custom orders, personalized gifts, and local media galleries.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Add artwork media

Put image files in:

```text
src/assets/images
```

Put video files in:

```text
src/assets/videos
```

The site automatically loads all supported files from those folders when rebuilt.
