# Brush&Bliss Local Assets

Add your artwork media here:

- Images: `src/assets/images`
- Videos: `src/assets/videos`

Supported image formats: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`, `.gif`

Supported video formats: `.mp4`, `.webm`, `.ogg`, `.mov`

After adding files, run:

```bash
npm install
npm run dev
```

The gallery imports all matching local files automatically.
